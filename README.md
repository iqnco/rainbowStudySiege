# Rainbow Study Siege

**Live:** [rainbowstudysiege.vercel.app](https://rainbowstudysiege.vercel.app)

A study app that turns exam prep into a tactical shooter menu. Pick a mission (a course),
pick a map (midterm or final), choose an operator and deploy into a round of exam-style
questions. Wrong answers cost armor, and your score earns a rank from Copper to Champion.

The first working version was built in two days, ahead of the Organizational Behavior
exams.

---

## What it does

- **Missions and maps.** Each course is a mission and each exam is a map. It currently
  ships Organizational Behavior, with a midterm and a final.
- **Ranked and Training Grounds.** Ranked plays a 10-question round across every chapter
  and counts toward the leaderboard. Training Grounds lets you choose which chapters to drill.
- **After Action Review.** A round built only from questions you've previously got wrong,
  so review goes where you're weakest.
- **Four question types:** multiple choice, fill in the blank, typed answers and
  match-the-pairs.
- **Armor instead of lives.** Three plates per round. Every miss shows an explanation of
  the right answer.
- **Wadie.** An AI study buddy grounded in the course chapters, for when an explanation
  isn't enough.
- **Accounts.** Sign-up, operator select, match history and a leaderboard.

## How it's built

| | |
|---|---|
| Framework | Next.js 15 (App Router), TypeScript, Tailwind |
| AI | Claude (`claude-sonnet-4-6`) for question generation, explanations and Wadie; OpenAI `gpt-image-1` for operator art |
| Data | Supabase for auth, scores, history and the leaderboard |
| Content | Parsed from course PDFs and DOCX files with `pdf-parse` and `mammoth` |
| Hosting | Vercel |

**How a round works.** Course material is loaded and the round follows a fixed rhythm of
question types (multiple choice, fill, multiple choice, typed, match...). Each question is
either drawn from the real exam bank or generated by Claude as typed JSON.

**Real exam questions first.** The first version generated every question with Claude. It
was fluent, but it didn't look like the exam, so the question bank was replaced with 154
real questions extracted from the chapter PDFs, including 15 whose answers weren't marked
in the source and had to be worked out.

This engine was later forked into [Capital BrainRot](https://github.com/iqnco/CapitalBrainRot)
for a different course, with an Italian brainrot theme instead of a tactical one.

## Running it locally

```bash
npm install
cp .env.local.example .env.local   # add ANTHROPIC_API_KEY (plus Supabase and OpenAI keys for accounts and art)
npm run dev                        # http://localhost:3000
```
